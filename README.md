# Mis deudas

Libreta para compras a meses sin intereses.

- Cuántos pagos van, por ejemplo 3 de 12.
- Cuánto llevas pagado y cuánto falta.
- El pago mensual lo pones tú.
- Puedes repartir cada compra entre una o más personas.
- Cada persona tiene nombre, y cada tarjeta tiene nombre y terminación de 4 dígitos.
- La compra puede ser tuya o de otra persona.

Los datos se quedan en el teléfono. No hay cuenta. La única consulta externa es el calendario público de días festivos de México, y solo se envía el año.
